# 📊 Bank Loan Analysis Dashboard

## Project Overview
This project analyzes bank loan data using SQL and Power BI to identify lending trends, loan performance, customer behavior, and financial KPIs.

## Objective
The objective of this project is to help financial institutions understand loan distribution, monitor loan status, and identify business insights through an interactive dashboard.

## Tools Used
- SQL
- Power BI
- Microsoft Excel

## Key KPIs
- Total Loan Applications
- Total Loan Amount
- Total Amount Received
- Average Interest Rate
- Average Debt-to-Income Ratio
- Good Loans vs Bad Loans
- State-wise Loan Distribution
- Loan Status Analysis
- Home Ownership Analysis

## Key Insights
- Identified states with the highest loan amounts.
- Compared verified and non-verified customers.
- Analyzed loan status distribution.
- Evaluated customer home ownership trends.
- Built an interactive Power BI dashboard for business decision-making.
